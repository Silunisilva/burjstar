# Burj Star — General Maintenance, Contracting & AMC Web Platform

> **Official Web Platform for Burj Star General Maintenance & Property Management LLC (Abu Dhabi, UAE)**  
> Premier Annual Maintenance Contracts (AMC), General Contracting, Turnkey Luxury Interior Fit-Outs, and MEP Engineering Services.

---

## 🌟 Overview

**Burj Star** is a modern, high-performance web application engineered for Abu Dhabi's premier contracting and facility management firm. Built with **React**, **Vite**, and **Tailwind CSS**, the platform delivers an ultra-luxurious, responsive, and interactive digital experience for residential villa owners, commercial towers, and enterprise facility managers.

---

## ✨ Key Features

- **🏛️ 16 Core Specialized Engineering Disciplines:** Comprehensive showcase spanning General Contracting, AC & HVAC Maintenance, Interior Designs, Civil Works, MEP Engineering, Fire Fighting Systems, Chiller Overhaul, Electrical, Plumbing, Marble Tiling, Carpentry, Painting, Waterproofing, and Building Maintenance.
- **📋 Interactive AMC Package Calculator:** Tiered Annual Maintenance Contracts tailored for Abu Dhabi properties (Luxury 6 BHK Villas, 4 BHK & 3 BHK+MR Apartments) with instant pricing and WhatsApp quote generation.
- **🔄 Interactive Before & After Visual Slider:** Real-time synchronized before/after image and 4K video frame comparison slider with dual view modes (Split Slider & Side-by-Side).
- **💼 Landmark Projects Portfolio & Video Reels:** Case studies with detailed engineering deliverables, before/after site documentation, and full 4K project video walkthroughs.
- **📱 WhatsApp Direct & Rapid Emergency Dispatch:** Integrated WhatsApp quote builders with auto-formatted inquiry templates and 24/7 hotline actions.
- **🎯 Full Mobile & Desktop Responsiveness:** Floating 3D vertical navigation dock, animated drawer menus, and SEO-optimized metadata.

## 🚀 Getting Started

### Prerequisites
- **Node.js:** `v18.x` or later
- **Package Manager:** `npm` or `yarn`

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/burjstar.git
   cd burjstar
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start local development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

5. Preview production build locally:
   ```bash
   npm run preview
   ```
